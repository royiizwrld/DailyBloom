# 🌱 Daily Bloom

Daily Bloom is a modern, responsive web application built to help users build lasting habits, keep daily streaks growing, and effortlessly manage routines with offline sync and AI assistance.

## Key Features

### Daily Checklist & Interactive Calendar
* **Quick Check-Ins:** Check off your day in seconds with a fast daily task list.
* **History Navigation:** Navigate past days, instantly undo actions, and track completion progress with a monthly calendar heatmap.

### Advanced Streak Tracking
* **Momentum Protection:** Current and longest streaks automatically respect each habit's custom schedule, ensuring rest days never break an active streak.

### Flexible Habits & Routines
* **Custom Habit Frequencies:** Create custom habits with icons, colors, and flexible schedules (every day, certain weekdays, or X times per week).
* **Routine Grouping:** Group habits into Morning, Afternoon, and Evening routines.

### AI Habit Coach & Bulk Add
* **Smart Coaching:** Ask the AI habit coach how your week went or which habit to focus on.
* **Smart Bulk Import:** Paste a whole routine description to instantly generate habits for review and saving.

### Offline-First with Auto-Sync
* **Seamless Offline Functionality:** Check off habits, add notes, and modify routines without an internet connection.
* **Cloud Sync:** Changes are queued locally and automatically synced to Lovable Cloud once back online.

### Installable PWA & Themes
* **Cross-Platform PWA:** Install directly to your phone or desktop home screen as a Progressive Web App.
* **Custom Styling:** Automatic light/dark mode support alongside custom accent color themes.

## Tech Stack
* **Frontend:** React, TypeScript, Vite, Tailwind CSS, Radix UI / Shadcn UI components.
* **Routing & State:** TanStack Router, React Context, persistent local cache & offline mutation queue.
* **Backend & Cloud:** Lovable Cloud (PostgreSQL database with Row-Level Security and secure Auth).
* **PWA Support:** Service Worker, web app manifest, custom icons, and install prompts.
